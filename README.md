# OTInstaller feedback

Bug reports and ideas for [OTInstaller](https://otinstaller.com): the registry and website, `ot` and otlite.

- **Bug:** [open a bug report](https://github.com/OTInstaller/feedback/issues/new?template=bug.yml) and pick a
  severity. `sev-1` means it blocks installing, running or publishing.
- **Idea or question:** [open an idea](https://github.com/OTInstaller/feedback/issues/new?template=idea.yml), or use
  https://otinstaller.com/feedback or `ot feedback "…"` for quick notes.
- **A published tool doesn't work or is out of date:** use **Report a problem** on the tool's page, which reaches the
  people who look after that package. Malware, abuse or a license problem goes privately to the reviewers from the
  same page.
- **Security problem** in OTInstaller itself: email security@otinstaller.com instead of opening an issue.

The code is open source in [OTInstaller/otinstaller](https://github.com/OTInstaller/otinstaller), and pull requests
are welcome there.
